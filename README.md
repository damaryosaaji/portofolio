# 👨‍💻 Damar - Minimalist Developer Portfolio

Sebuah website portofolio pribadi satu halaman (*single-page*) yang dirancang dengan estetika modern, bersih, dan terinspirasi dari antarmuka iOS (Apple Design Guidelines). Portofolio ini sangat cocok untuk Frontend Developer, Programmer, atau Project Leader yang ingin menampilkan karyanya dengan elegan.

![Portfolio Preview](https://via.placeholder.com/1000x500.png?text=Preview+Portfolio+Damar) ## ✨ Fitur Utama

* **iOS 26 Inspired Design**: Menggunakan mode terang (*light theme*), *glassmorphism* (efek kaca blur), sudut membulat (*squircle*), dan bayangan halus untuk kesan premium.
* **Interactive Aurora Hero**: Latar belakang bagian atas (*Hero Section*) dilengkapi dengan efek aurora yang bergerak dinamis (*parallax*) dan merespons pergerakan kursor mouse.
* **Bento Grid Layout**: Menampilkan area spesialisasi menggunakan *layout grid masonry* bergaya Bento yang sedang tren.
* **Modern Tabbed Portfolio**: Menampilkan proyek, sertifikasi, dan teknologi (*Tech Stack*) dalam satu area yang rapi tanpa perlu berpindah halaman.
* **Fully Responsive**: Tampilan yang menyesuaikan dengan sempurna di perangkat seluler (*mobile*), tablet, dan desktop.
* **Zero Dependencies Build**: Tidak memerlukan *Node.js*, *bundler*, atau *backend*. Murni menggunakan CDN untuk performa yang sangat cepat.

## 🛠️ Teknologi yang Digunakan

* **HTML5** & **CSS3** (Custom Styles)
* **Bootstrap 5.3** (CSS Framework & Grid System)
* **Bootstrap Icons** (Ikon SVG)
* **Vanilla JavaScript** (Untuk fungsionalitas Tab dan interaksi kursor Aurora)

## 🚀 Cara Penggunaan & Deployment

Karena website ini berupa file statis murni, Anda dapat menjalankannya langsung di *browser* atau meng-hostingnya secara gratis di **GitHub Pages**.

### Menjalankan Secara Lokal
1. *Clone* repositori ini: `git clone https://github.com/username-anda/nama-repo-anda.git`
2. Buka folder proyek.
3. Klik dua kali pada file `index.html` untuk membukanya di *browser* Anda.

### Hosting Gratis di GitHub Pages
1. Unggah/Push file `index.html` ini ke repositori GitHub Anda.
2. Pergi ke tab **Settings** di repositori Anda.
3. Di *sidebar* sebelah kiri, klik menu **Pages**.
4. Pada bagian *Build and deployment*, pilih *Source*: **Deploy from a branch**.
5. Pilih *Branch*: **main** atau **master**, lalu klik **Save**.
6. Tunggu beberapa menit, website Anda akan *live* di `https://username-anda.github.io/nama-repo-anda/`.

## 🎨 Kustomisasi (Untuk Anda Sendiri)

Jika Anda ingin menggunakan ulang template ini, silakan sesuaikan bagian berikut di dalam file `index.html`:
* **Metadata**: Ubah `<title>` dan tag meta.
* **Teks & Konten**: Cari teks "Damar" dan ganti dengan nama dan copywriting Anda sendiri.
* **Gambar/Aset**: Ganti URL gambar berawalan `https://via.placeholder.com/...` dengan URL gambar asli Anda atau letakkan gambar di folder lokal (misal: `<img src="./assets/foto-profil.jpg">`).
* **Tautan**: Perbarui tautan `#` pada tombol "Hubungi Saya", LinkedIn, GitHub, dan Email dengan tautan profil Anda yang sebenarnya.
